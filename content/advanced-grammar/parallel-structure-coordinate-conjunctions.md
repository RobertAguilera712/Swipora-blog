Title: Parallel Structures With Coordinate Conjunctions
Date: 2026-09-13
Category: Advanced Grammar
Tags: Advance Grammar, TOEFL Preparation
Summary: Learn how to use parallel structure with coordinate conjunctions 

In English we always try to make the sentence as even and balanced as possible, we are kind of perfectionist. Take a look to the following examples:

<div class="grammar">
I like <span class='grammar-blue'>to read</span> <span class='grammar-purple'>and</span> <span class='grammar-red'>writing</span>
</div>
<sub>
**\*<span class='grammar-blue'>Infinitive (TO followed by a BASE VERB)</span>**<br>
**\*<span class='grammar-red'>Gerund (VERB ING)</span>**<br>
**\*<span class='grammar-purple'>AND (Coordinate Conjunction)</span>**<br>
</sub>

In the previous example, we have a simple sentence that express our interests
using the verb **LIKE**. As we know, this verb can be followed either by an
**<span class='grammar-blue'>Infinitive</span>** or by a **<span class='grammar-red'>Gerund</span>**, 
so the sentence: **"I like <span class='grammar-blue'>to read</span>"** and **"I like <span class='grammar-red'>writing</span>"**
are correct as independent sentences.

Now, when both are joined using **<span class='grammar-purple'>and</span>** we have to **"balance"** the sentence. Either we put 
both parts using **<span class='grammar-blue'>infinitives</span>** or we put both parts using **<span class='grammar-red'>Gerunds</span>**
so to fix the first wrong example we can make it as follows:

<div class="grammar">
I like <span class='grammar-blue'>to read</span> <span class='grammar-purple'>and</span> <span class='grammar-blue'>to write</span><br>
I like <span class='grammar-red'>reading</span> <span class='grammar-purple'>and</span> <span class='grammar-red'>writing</span>
</div>
<sub>
**\*<span class='grammar-blue'>Infinitive (TO followed by a BASE VERB)</span>**<br>
**\*<span class='grammar-red'>Gerund (VERB ING)</span>**<br>
**\*<span class='grammar-purple'>AND (Coordinate Conjunction)</span>**<br>
</sub>

This balance must be applied when joining **adjectives, nouns, phrases and clauses** with the **Coordinate Conjunctions**
**<span class='grammar-purple'>And, But & Or</span>**.

<div class="grammar">
She is <span class='grammar-pink'>smart</span> <span class='grammar-purple'>and</span> <span class='grammar-pink'>beautiful</span><br>
The car is not <span class='grammar-pink'>fast</span> <span class='grammar-purple'>but</span> <span class='grammar-pink'>efficient</span><br>
Look at her face, she may be <span class='grammar-pink'>angry</span> <span class='grammar-purple'>or</span> <span class='grammar-pink'>sad</span>
</div>
<sub>
**\*<span class='grammar-pink'>Adjectives</span>**<br>
**\*<span class='grammar-purple'>(Coordinate Conjunction)</span>**<br>
</sub>

<div class="grammar">
I am an <span class='grammar-orange'>engineer</span> <span class='grammar-purple'>and</span> a <span class='grammar-orange'>teacher</span><br>
She is not a <span class='grammar-orange'>nurse</span> <span class='grammar-purple'>but</span> a <span class='grammar-orange'>doctor</span><br>
We need to talk to the <span class='grammar-orange'>coordinator</span> <span class='grammar-purple'>or</span> to his <span class='grammar-orange'>assistant</span>
</div>
<sub>
**\*<span class='grammar-orange'>Nouns</span>**<br>
**\*<span class='grammar-purple'>(Coordinate Conjunction)</span>**<br>
</sub>

<div class="grammar">
I <span class='grammar-red'>cooked</span> 
<span class='grammar-purple'>and</span> <span class='grammar-red'>ate</span> pizza yesterday<br>
He doesn't <span class='grammar-red'>clean</span> <span class='grammar-purple'>but</span> <span class='grammar-red'>cooks</span> for her<br>
You can <span class='grammar-red'>run</span> <span class='grammar-purple'>or</span> <span class='grammar-red'>walk</span> during the race
</div>
<sub>
**\*<span class='grammar-red'>Verbs</span>**<br>
**\*<span class='grammar-purple'>(Coordinate Conjunction)</span>**<br>
</sub>
