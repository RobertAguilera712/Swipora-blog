Summary: Aprende a expresar obligaciones, necesidades y consejos con have to, must y should.

En inglés usamos **have to** y **must** para hablar de obligaciones, mientras que **should** sirve para dar consejos. Aunque estas expresiones pueden parecer similares, no comunican el mismo grado de importancia.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>finish</span> my homework.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-pink'>tengo que</span> <span class='grammar-blue'>terminar</span> mi tarea.<br><br>
:us: <span class='grammar-green'>Students</span> <span class='grammar-pink'>must</span> <span class='grammar-blue'>follow</span> the rules.<br>
:mexico: <span class='grammar-green'>Los estudiantes</span> <span class='grammar-pink'>deben</span> <span class='grammar-blue'>seguir</span> las reglas.<br><br>
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>should</span> <span class='grammar-blue'>sleep</span> more.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-pink'>deberías</span> <span class='grammar-blue'>dormir</span> más.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Obligation or advice expression (expresión de obligación o consejo).</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

En estos ejemplos, terminar la tarea y seguir las reglas son obligaciones. Dormir más es solamente una recomendación.

## Obligaciones y necesidades con Have To

Usamos **have to** para expresar que una acción es necesaria. La obligación normalmente viene de una situación, una responsabilidad, un horario o una regla externa.

### Forma afirmativa

Después de **have to** o **has to**, usamos un verbo en su forma base. Con **he**, **she** e **it** usamos **has to**; con los demás sujetos usamos **have to**.

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-pink'>have to / has to</span> + <span class='grammar-blue'>base verb</span> + complement
</div>

<div class="grammar" markdown="1">
<span class='grammar-green'>I / You / We / They</span> → <span class='grammar-pink'>have to</span><br>
<span class='grammar-green'>He / She / It</span> → <span class='grammar-pink'>has to</span>
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>do</span> my homework.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-pink'>tengo que</span> <span class='grammar-blue'>hacer</span> mi tarea.<br><br>
:us: <span class='grammar-green'>She</span> <span class='grammar-pink'>has to</span> <span class='grammar-blue'>clean</span> her room.<br>
:mexico: <span class='grammar-green'>Ella</span> <span class='grammar-pink'>tiene que</span> <span class='grammar-blue'>limpiar</span> su habitación.<br><br>
:us: <span class='grammar-green'>We</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>arrive</span> at eight.<br>
:mexico: <span class='grammar-green'>Nosotros</span> <span class='grammar-pink'>tenemos que</span> <span class='grammar-blue'>llegar</span> a las ocho.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Have to or has to.</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

### Forma negativa: no es necesario

Usamos **don't have to** o **doesn't have to** para decir que una acción **no es necesaria**. La persona puede realizarla si quiere, pero no tiene la obligación de hacerlo.

Observa que **has to** cambia a **have to** cuando usamos el auxiliar **doesn't**.

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-red'>don't / doesn't</span> + <span class='grammar-pink'>have to</span> + <span class='grammar-blue'>base verb</span>
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-red'>don't</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>work</span> on Sunday.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>tengo que</span> <span class='grammar-blue'>trabajar</span> el domingo.<br><br>
:us: <span class='grammar-green'>He</span> <span class='grammar-red'>doesn't</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>bring</span> any food.<br>
:mexico: <span class='grammar-green'>Él</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>tiene que</span> <span class='grammar-blue'>traer</span> comida.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-red'>Negative auxiliary (auxiliar negativo).</span>**<br>
**\*<span class='grammar-pink'>Have to.</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

### Preguntas con Have To

Para hacer preguntas, colocamos **do** o **does** antes del sujeto. Después del sujeto siempre usamos **have to**, incluso cuando preguntamos por **he**, **she** o **it**.

<div class="grammar" markdown="1">
<span class='grammar-orange'>Do / Does</span> + <span class='grammar-green'>subject</span> + <span class='grammar-pink'>have to</span> + <span class='grammar-blue'>base verb</span> + ?
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-orange'>Do</span> <span class='grammar-green'>you</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>work</span> on Saturday?<br>
:mexico: ¿<span class='grammar-green'>Tú</span> <span class='grammar-pink'>tienes que</span> <span class='grammar-blue'>trabajar</span> el sábado?<br><br>
:us: <span class='grammar-orange'>Does</span> <span class='grammar-green'>Ana</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>wear</span> a uniform?<br>
:mexico: ¿<span class='grammar-green'>Ana</span> <span class='grammar-pink'>tiene que</span> <span class='grammar-blue'>usar</span> uniforme?
</div>

<sub>**\*<span class='grammar-orange'>Question auxiliary (auxiliar de pregunta).</span>**<br>
**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Have to.</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

Las respuestas cortas usan **do** o **does**, no *have*.

<div class="grammar" markdown="1">
:us: Yes, <span class='grammar-green'>I</span> <span class='grammar-orange'>do</span>. / <span class='grammar-red'>No</span>, <span class='grammar-green'>I</span> <span class='grammar-red'>don't</span>.<br>
:mexico: Sí, <span class='grammar-green'>yo</span> tengo que hacerlo. / <span class='grammar-red'>No</span>, <span class='grammar-green'>yo</span> <span class='grammar-red'>no</span> tengo que hacerlo.<br><br>
:us: Yes, <span class='grammar-green'>she</span> <span class='grammar-orange'>does</span>. / <span class='grammar-red'>No</span>, <span class='grammar-green'>she</span> <span class='grammar-red'>doesn't</span>.<br>
:mexico: Sí, <span class='grammar-green'>ella</span> tiene que hacerlo. / <span class='grammar-red'>No</span>, <span class='grammar-green'>ella</span> <span class='grammar-red'>no</span> tiene que hacerlo.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-orange'>Affirmative auxiliary (auxiliar afirmativo).</span>**<br>
**\*<span class='grammar-red'>Negative answer or auxiliary (respuesta o auxiliar negativo).</span>**</sub>

También podemos usar una palabra interrogativa antes de **do** o **does**.

<div class="grammar" markdown="1">
:us: Mom, <span class='grammar-purple'>why</span> <span class='grammar-orange'>do</span> <span class='grammar-green'>I</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>clean</span> my room?<br>
:mexico: Mamá, ¿<span class='grammar-purple'>por qué</span> <span class='grammar-green'>yo</span> <span class='grammar-pink'>tengo que</span> <span class='grammar-blue'>limpiar</span> mi habitación?<br><br>
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>clean</span> it because I told you to.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-pink'>tienes que</span> <span class='grammar-blue'>limpiarla</span> porque yo lo digo.
</div>

<sub>**\*<span class='grammar-purple'>Question word (palabra interrogativa).</span>**<br>
**\*<span class='grammar-orange'>Question auxiliary (auxiliar de pregunta).</span>**<br>
**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Have to.</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

## Obligaciones fuertes y reglas con Must

Usamos **must** para comunicar una obligación fuerte. Es común en reglas, instrucciones, avisos y situaciones que la persona que habla considera muy importantes.

**Must** no cambia con el sujeto y siempre va seguido de un verbo en forma base. Nunca usamos *musts* ni *must to*.

### Forma afirmativa

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-pink'>must</span> + <span class='grammar-blue'>base verb</span> + complement
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>Students</span> <span class='grammar-pink'>must</span> <span class='grammar-blue'>attend</span> class.<br>
:mexico: <span class='grammar-green'>Los estudiantes</span> <span class='grammar-pink'>deben</span> <span class='grammar-blue'>asistir</span> a clase.<br><br>
:us: <span class='grammar-green'>All passengers</span> <span class='grammar-pink'>must</span> <span class='grammar-blue'>wear</span> a seat belt.<br>
:mexico: <span class='grammar-green'>Todos los pasajeros</span> <span class='grammar-pink'>deben</span> <span class='grammar-blue'>usar</span> el cinturón de seguridad.<br><br>
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>must</span> <span class='grammar-blue'>wash</span> your hands before cooking.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-pink'>debes</span> <span class='grammar-blue'>lavarte</span> las manos antes de cocinar.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Must.</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

### Forma negativa: prohibición

**Must not** o su contracción **mustn't** significa que algo está prohibido. No significa que la acción sea opcional.

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-pink'>must</span> + <span class='grammar-red'>not</span> + <span class='grammar-blue'>base verb</span>
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>Students</span> <span class='grammar-pink'>must</span> <span class='grammar-red'>not</span> <span class='grammar-blue'>use</span> their phones during class.<br>
:mexico: <span class='grammar-green'>Los estudiantes</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>deben</span> <span class='grammar-blue'>usar</span> el celular durante la clase.<br><br>
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>must</span><span class='grammar-red'>n't</span> <span class='grammar-blue'>touch</span> that hot pan.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>debes</span> <span class='grammar-blue'>tocar</span> esa sartén caliente.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Must.</span>**<br>
**\*<span class='grammar-red'>Negation, including the apostrophe (negación, incluido el apóstrofo).</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

### Must not y Don't have to no significan lo mismo

Esta diferencia es muy importante:

- **Must not** significa **no debes hacerlo** porque está prohibido.
- **Don't have to** significa **no tienes que hacerlo** porque no es necesario.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>must</span> <span class='grammar-red'>not</span> <span class='grammar-blue'>enter</span> the kitchen.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>debes</span> <span class='grammar-blue'>entrar</span> a la cocina. Está prohibido.<br><br>
:us: <span class='grammar-green'>You</span> <span class='grammar-red'>don't</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>enter</span> the kitchen.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>tienes que</span> <span class='grammar-blue'>entrar</span> a la cocina. No es necesario.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Must or have to.</span>**<br>
**\*<span class='grammar-red'>Negation (negación).</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

## Consejos con Should

Usamos **should** para recomendar una acción o decir qué creemos que es conveniente. Es un consejo, no una obligación. La persona puede decidir si sigue la recomendación.

**Should** no cambia con el sujeto y va seguido de un verbo en forma base. Nunca usamos *shoulds* ni *should to*.

### Forma afirmativa

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-pink'>should</span> + <span class='grammar-blue'>base verb</span> + complement
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>should</span> <span class='grammar-blue'>try</span> Italian food.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-pink'>deberías</span> <span class='grammar-blue'>probar</span> la comida italiana.<br><br>
:us: <span class='grammar-green'>He</span> <span class='grammar-pink'>should</span> <span class='grammar-blue'>drink</span> more water.<br>
:mexico: <span class='grammar-green'>Él</span> <span class='grammar-pink'>debería</span> <span class='grammar-blue'>tomar</span> más agua.<br><br>
:us: <span class='grammar-green'>We</span> <span class='grammar-pink'>should</span> <span class='grammar-blue'>leave</span> early.<br>
:mexico: <span class='grammar-green'>Nosotros</span> <span class='grammar-pink'>deberíamos</span> <span class='grammar-blue'>salir</span> temprano.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Should.</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

### Forma negativa

Usamos **should not** o su contracción **shouldn't** para aconsejar que una persona evite una acción.

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-pink'>should</span> + <span class='grammar-red'>not</span> + <span class='grammar-blue'>base verb</span>
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>should</span> <span class='grammar-red'>not</span> <span class='grammar-blue'>eat</span> so much sugar.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>debería</span> <span class='grammar-blue'>comer</span> tanta azúcar.<br><br>
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>should</span><span class='grammar-red'>n't</span> <span class='grammar-blue'>skip</span> breakfast.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>deberías</span> <span class='grammar-blue'>saltarte</span> el desayuno.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Should.</span>**<br>
**\*<span class='grammar-red'>Negation, including the apostrophe (negación, incluido el apóstrofo).</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

### Preguntas con Should

Para pedir un consejo, colocamos **should** antes del sujeto.

<div class="grammar" markdown="1">
<span class='grammar-pink'>Should</span> + <span class='grammar-green'>subject</span> + <span class='grammar-blue'>base verb</span> + ?
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-pink'>Should</span> <span class='grammar-green'>I</span> <span class='grammar-blue'>call</span> the doctor?<br>
:mexico: ¿<span class='grammar-pink'>Debería</span> <span class='grammar-green'>yo</span> <span class='grammar-blue'>llamar</span> al médico?<br><br>
:us: <span class='grammar-purple'>What</span> <span class='grammar-pink'>should</span> <span class='grammar-green'>we</span> <span class='grammar-blue'>cook</span> for dinner?<br>
:mexico: ¿<span class='grammar-purple'>Qué</span> <span class='grammar-pink'>deberíamos</span> <span class='grammar-blue'>cocinar</span> <span class='grammar-green'>nosotros</span> para la cena?
</div>

<sub>**\*<span class='grammar-purple'>Question word (palabra interrogativa).</span>**<br>
**\*<span class='grammar-pink'>Should.</span>**<br>
**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

## Advice vs. Obligation

La diferencia principal está en la fuerza de la idea:

- **Should** expresa un consejo. Es una buena idea, pero no es obligatorio.
- **Have to** expresa una necesidad u obligación causada normalmente por una situación o regla externa.
- **Must** expresa una obligación fuerte, una regla o algo que la persona considera esencial.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>should</span> <span class='grammar-blue'>wear</span> comfortable shoes.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-pink'>deberías</span> <span class='grammar-blue'>usar</span> zapatos cómodos. Es un consejo.<br><br>
:us: <span class='grammar-green'>Employees</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>wear</span> a uniform.<br>
:mexico: <span class='grammar-green'>Los empleados</span> <span class='grammar-pink'>tienen que</span> <span class='grammar-blue'>usar</span> uniforme. Es un requisito del trabajo.<br><br>
:us: <span class='grammar-green'>Kitchen staff</span> <span class='grammar-pink'>must</span> <span class='grammar-blue'>follow</span> food-safety rules.<br>
:mexico: <span class='grammar-green'>El personal de cocina</span> <span class='grammar-pink'>debe</span> <span class='grammar-blue'>seguir</span> las reglas de seguridad alimentaria. Es una obligación importante.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Advice or obligation expression (expresión de consejo u obligación).</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

## Errores comunes

Después de **have to**, **must** y **should**, debemos usar la forma base del verbo. Además, **must** y **should** no llevan **to**.

<div class="grammar" markdown="1">
:x: <span class='grammar-green'>She</span> <span class='grammar-pink'>have to</span> <span class='grammar-blue'>works</span> today.<br>
:white_check_mark: <span class='grammar-green'>She</span> <span class='grammar-pink'>has to</span> <span class='grammar-blue'>work</span> today.<br>
:mexico: <span class='grammar-green'>Ella</span> <span class='grammar-pink'>tiene que</span> <span class='grammar-blue'>trabajar</span> hoy.<br><br>
:x: <span class='grammar-green'>You</span> <span class='grammar-pink'>must to</span> <span class='grammar-blue'>wear</span> gloves.<br>
:white_check_mark: <span class='grammar-green'>You</span> <span class='grammar-pink'>must</span> <span class='grammar-blue'>wear</span> gloves.<br>
:mexico: <span class='grammar-green'>Tú</span> <span class='grammar-pink'>debes</span> <span class='grammar-blue'>usar</span> guantes.<br><br>
:x: <span class='grammar-green'>He</span> <span class='grammar-pink'>should</span> <span class='grammar-blue'>eats</span> better.<br>
:white_check_mark: <span class='grammar-green'>He</span> <span class='grammar-pink'>should</span> <span class='grammar-blue'>eat</span> better.<br>
:mexico: <span class='grammar-green'>Él</span> <span class='grammar-pink'>debería</span> <span class='grammar-blue'>comer</span> mejor.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Have to, must or should.</span>**<br>
**\*<span class='grammar-blue'>Verb (verbo).</span>**</sub>
