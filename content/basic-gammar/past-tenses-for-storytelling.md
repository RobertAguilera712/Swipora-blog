Title: Past Tenses for Storytelling
Date: 2026-10-06
Category: Basic Grammar
Tags: Gramática Básica, Simple Past, Past Progressive, Past Perfect, Storytelling
Summary: Aprende a combinar el pasado simple, el pasado progresivo y el pasado perfecto para contar historias.

Cuando contamos una historia en inglés, no todas las acciones cumplen la misma función. Algunas hacen avanzar la historia, otras describen lo que estaba ocurriendo en ese momento y otras explican algo que ya había sucedido.

Para organizar estas ideas usamos tres tiempos verbales:

- **Simple past:** presenta las acciones principales de la historia.
- **Past progressive:** describe una acción que estaba en progreso o establece la escena.
- **Past perfect:** muestra que una acción ocurrió antes de otra acción pasada.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-blue'>met</span> Sophie while <span class='grammar-green'>we</span> <span class='grammar-pink'>were</span> <span class='grammar-blue'>traveling</span> to Guanajuato. <span class='grammar-green'>She</span> <span class='grammar-pink'>had</span> already <span class='grammar-blue'>studied</span> Spanish before the trip.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-blue'>conocí</span> a Sophie mientras <span class='grammar-green'>nosotros</span> <span class='grammar-pink'>viajábamos</span> a Guanajuato. <span class='grammar-green'>Ella</span> ya <span class='grammar-pink'>había</span> <span class='grammar-blue'>estudiado</span> español antes del viaje.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Auxiliary verb (verbo auxiliar).</span>**<br>
**\*<span class='grammar-blue'>Main verb (verbo principal).</span>**</sub>

## Simple Past

Usamos el **simple past** para hablar de acciones que comenzaron y terminaron en el pasado. Al contar una historia, este tiempo presenta los eventos principales en el orden en que ocurrieron.

### Forma afirmativa

Los verbos regulares normalmente terminan en **-ed**. Los verbos irregulares tienen una forma especial que debemos aprender.

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-blue'>verb in past</span> + complement
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>The teacher</span> <span class='grammar-blue'>shared</span> some good news.<br>
:mexico: <span class='grammar-green'>La maestra</span> <span class='grammar-blue'>compartió</span> una buena noticia.<br><br>
:us: <span class='grammar-green'>I</span> <span class='grammar-blue'>met</span> Sophie during the trip.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-blue'>conocí</span> a Sophie durante el viaje.<br><br>
:us: <span class='grammar-green'>We</span> <span class='grammar-blue'>played</span> soccer, <span class='grammar-blue'>ate</span> guacamayas, and <span class='grammar-blue'>visited</span> Guanajuato.<br>
:mexico: <span class='grammar-green'>Nosotros</span> <span class='grammar-blue'>jugamos</span> futbol, <span class='grammar-blue'>comimos</span> guacamayas y <span class='grammar-blue'>visitamos</span> Guanajuato.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-blue'>Verb in the simple past (verbo en pasado simple).</span>**</sub>

### Forma negativa

Para formar una oración negativa usamos **did not** o **didn't** y regresamos el verbo principal a su forma base.

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-red'>did not / didn't</span> + <span class='grammar-blue'>base verb</span> + complement
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-red'>didn't</span> <span class='grammar-blue'>talk</span> to her that day.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-red'>no</span> <span class='grammar-blue'>hablé</span> con ella ese día.<br><br>
:us: <span class='grammar-green'>She</span> <span class='grammar-red'>did not</span> <span class='grammar-blue'>speak</span> much English.<br>
:mexico: <span class='grammar-green'>Ella</span> <span class='grammar-red'>no</span> <span class='grammar-blue'>hablaba</span> mucho inglés.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-red'>Negative auxiliary (auxiliar negativo).</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

### Preguntas

Para hacer preguntas colocamos **did** antes del sujeto y usamos el verbo principal en su forma base.

<div class="grammar" markdown="1">
<span class='grammar-orange'>Did</span> + <span class='grammar-green'>subject</span> + <span class='grammar-blue'>base verb</span> + ?
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-orange'>Did</span> <span class='grammar-green'>you</span> <span class='grammar-blue'>enjoy</span> the trip?<br>
:mexico: ¿<span class='grammar-green'>Tú</span> <span class='grammar-blue'>disfrutaste</span> el viaje?<br><br>
:us: <span class='grammar-purple'>What</span> <span class='grammar-orange'>did</span> <span class='grammar-green'>the students</span> <span class='grammar-blue'>do</span> in Guanajuato?<br>
:mexico: ¿<span class='grammar-purple'>Qué</span> <span class='grammar-blue'>hicieron</span> <span class='grammar-green'>los estudiantes</span> en Guanajuato?
</div>

<sub>**\*<span class='grammar-purple'>Question word (palabra interrogativa).</span>**<br>
**\*<span class='grammar-orange'>Question auxiliary (auxiliar de pregunta).</span>**<br>
**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-blue'>Base verb (verbo en forma base).</span>**</sub>

## Past Progressive

Usamos el **past progressive**, también llamado **past continuous**, para describir una acción que estaba en progreso en un momento del pasado. En una historia, ayuda a establecer la escena o describir lo que estaba ocurriendo alrededor de una acción principal.

### Forma afirmativa

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-pink'>was / were</span> + <span class='grammar-blue'>verb + ing</span> + complement
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>was</span> <span class='grammar-blue'>taking</span> my English class.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-pink'>estaba</span> <span class='grammar-blue'>tomando</span> mi clase de inglés.<br><br>
:us: <span class='grammar-green'>The students</span> <span class='grammar-pink'>were</span> <span class='grammar-blue'>traveling</span> to Guanajuato.<br>
:mexico: <span class='grammar-green'>Los estudiantes</span> <span class='grammar-pink'>estaban</span> <span class='grammar-blue'>viajando</span> a Guanajuato.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Was or were.</span>**<br>
**\*<span class='grammar-blue'>Verb + ing (verbo con -ing).</span>**</sub>

### Forma negativa y preguntas

Colocamos **not** después de **was** o **were** para negar. En preguntas, colocamos **was** o **were** antes del sujeto.

<div class="grammar" markdown="1">
Negative: <span class='grammar-green'>subject</span> + <span class='grammar-pink'>was / were</span> + <span class='grammar-red'>not</span> + <span class='grammar-blue'>verb + ing</span><br>
Question: <span class='grammar-pink'>Was / Were</span> + <span class='grammar-green'>subject</span> + <span class='grammar-blue'>verb + ing</span> + ?
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>was</span><span class='grammar-red'>n't</span> <span class='grammar-blue'>speaking</span> English confidently.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>estaba</span> <span class='grammar-blue'>hablando</span> inglés con seguridad.<br><br>
:us: <span class='grammar-pink'>Were</span> <span class='grammar-green'>you</span> <span class='grammar-blue'>studying</span> when the teacher called?<br>
:mexico: ¿<span class='grammar-green'>Tú</span> <span class='grammar-pink'>estabas</span> <span class='grammar-blue'>estudiando</span> cuando llamó la maestra?
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Was or were.</span>**<br>
**\*<span class='grammar-red'>Negation, including the apostrophe (negación, incluido el apóstrofo).</span>**<br>
**\*<span class='grammar-blue'>Verb + ing (verbo con -ing).</span>**</sub>

## Simple Past and Past Progressive

Usamos el **past progressive** para la acción que estaba en progreso y el **simple past** para la acción corta que ocurrió durante ella o la interrumpió.

<div class="grammar" markdown="1">
<span class='grammar-purple'>While</span> + <span class='grammar-green'>subject</span> + <span class='grammar-pink'>was / were</span> + <span class='grammar-blue'>verb + ing</span>, <span class='grammar-green'>subject</span> + <span class='grammar-blue'>simple past verb</span>
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-purple'>While</span> <span class='grammar-green'>I</span> <span class='grammar-pink'>was</span> <span class='grammar-blue'>taking</span> the class, <span class='grammar-green'>the teacher</span> <span class='grammar-blue'>shared</span> some good news.<br>
:mexico: <span class='grammar-purple'>Mientras</span> <span class='grammar-green'>yo</span> <span class='grammar-pink'>estaba</span> <span class='grammar-blue'>tomando</span> la clase, <span class='grammar-green'>la maestra</span> <span class='grammar-blue'>compartió</span> una buena noticia.<br><br>
:us: <span class='grammar-green'>We</span> <span class='grammar-pink'>were</span> <span class='grammar-blue'>traveling</span> to Guanajuato <span class='grammar-purple'>when</span> <span class='grammar-green'>I</span> <span class='grammar-blue'>saw</span> Sophie.<br>
:mexico: <span class='grammar-green'>Nosotros</span> <span class='grammar-pink'>estábamos</span> <span class='grammar-blue'>viajando</span> a Guanajuato <span class='grammar-purple'>cuando</span> <span class='grammar-green'>yo</span> <span class='grammar-blue'>vi</span> a Sophie.
</div>

<sub>**\*<span class='grammar-purple'>Time connector (conector de tiempo).</span>**<br>
**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Was or were.</span>**<br>
**\*<span class='grammar-blue'>Verb (verbo).</span>**</sub>

Normalmente usamos **while** antes de la acción larga y **when** antes de la acción corta. La idea más importante es identificar cuál acción estaba en progreso y cuál hizo avanzar la historia.

## Past Perfect

Usamos el **past perfect** para mostrar que una acción ocurrió antes de otra acción pasada. Se forma con **had + past participle** y no cambia con el sujeto.

### Forma afirmativa

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-pink'>had</span> + <span class='grammar-blue'>past participle</span> + complement
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>Sophie</span> <span class='grammar-pink'>had</span> already <span class='grammar-blue'>studied</span> Spanish before the trip.<br>
:mexico: <span class='grammar-green'>Sophie</span> ya <span class='grammar-pink'>había</span> <span class='grammar-blue'>estudiado</span> español antes del viaje.<br><br>
:us: By the time <span class='grammar-green'>I</span> finished college, <span class='grammar-green'>I</span> <span class='grammar-pink'>had</span> already <span class='grammar-blue'>taken</span> the TOEFL.<br>
:mexico: Para cuando <span class='grammar-green'>yo</span> terminé la universidad, <span class='grammar-green'>yo</span> ya <span class='grammar-pink'>había</span> <span class='grammar-blue'>presentado</span> el TOEFL.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Had.</span>**<br>
**\*<span class='grammar-blue'>Past participle (participio pasado).</span>**</sub>

### Forma negativa y preguntas

<div class="grammar" markdown="1">
Negative: <span class='grammar-green'>subject</span> + <span class='grammar-pink'>had</span> + <span class='grammar-red'>not</span> + <span class='grammar-blue'>past participle</span><br>
Question: <span class='grammar-pink'>Had</span> + <span class='grammar-green'>subject</span> + <span class='grammar-blue'>past participle</span> + ?
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>had</span><span class='grammar-red'>n't</span> <span class='grammar-blue'>spoken</span> with a native speaker before that day.<br>
:mexico: <span class='grammar-green'>Yo</span> <span class='grammar-red'>no</span> <span class='grammar-pink'>había</span> <span class='grammar-blue'>hablado</span> con un hablante nativo antes de ese día.<br><br>
:us: <span class='grammar-pink'>Had</span> <span class='grammar-green'>she</span> <span class='grammar-blue'>learned</span> Spanish before she arrived?<br>
:mexico: ¿<span class='grammar-green'>Ella</span> <span class='grammar-pink'>había</span> <span class='grammar-blue'>aprendido</span> español antes de llegar?
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Had.</span>**<br>
**\*<span class='grammar-red'>Negation, including the apostrophe (negación, incluido el apóstrofo).</span>**<br>
**\*<span class='grammar-blue'>Past participle (participio pasado).</span>**</sub>

## Simple Past and Past Perfect

Cuando mencionamos dos acciones pasadas, usamos el **past perfect** para la acción que ocurrió primero y el **simple past** para la acción posterior.

<div class="grammar" markdown="1">
Earlier action: <span class='grammar-green'>subject</span> + <span class='grammar-pink'>had</span> + <span class='grammar-blue'>past participle</span><br>
Later action: <span class='grammar-green'>subject</span> + <span class='grammar-blue'>simple past verb</span>
</div>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>Sophie</span> <span class='grammar-pink'>had</span> <span class='grammar-blue'>studied</span> Spanish before <span class='grammar-green'>she</span> <span class='grammar-blue'>came</span> to Mexico.<br>
:mexico: <span class='grammar-green'>Sophie</span> <span class='grammar-pink'>había</span> <span class='grammar-blue'>estudiado</span> español antes de que <span class='grammar-green'>ella</span> <span class='grammar-blue'>viniera</span> a México.<br><br>
:us: <span class='grammar-purple'>By the time</span> <span class='grammar-green'>I</span> <span class='grammar-blue'>finished</span> college, <span class='grammar-green'>I</span> <span class='grammar-pink'>had</span> already <span class='grammar-blue'>taken</span> the TOEFL.<br>
:mexico: <span class='grammar-purple'>Para cuando</span> <span class='grammar-green'>yo</span> <span class='grammar-blue'>terminé</span> la universidad, <span class='grammar-green'>yo</span> ya <span class='grammar-pink'>había</span> <span class='grammar-blue'>presentado</span> el TOEFL.
</div>

<sub>**\*<span class='grammar-purple'>Time connector (conector de tiempo).</span>**<br>
**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Had.</span>**<br>
**\*<span class='grammar-blue'>Verb (verbo).</span>**</sub>

No es necesario usar el past perfect en todas las oraciones de una historia. Úsalo cuando necesites regresar a un evento anterior y aclarar el orden de dos acciones pasadas.

## Cómo combinar los tres tiempos

Una historia clara puede seguir este patrón:

1. Usa el **past progressive** para establecer la escena.
2. Usa el **simple past** para presentar los eventos principales.
3. Usa el **past perfect** para explicar algo que ya había ocurrido.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>We</span> <span class='grammar-pink'>were</span> <span class='grammar-blue'>traveling</span> to Guanajuato when <span class='grammar-green'>I</span> <span class='grammar-blue'>saw</span> Sophie. <span class='grammar-green'>She</span> <span class='grammar-pink'>had</span> already <span class='grammar-blue'>studied</span> Spanish, so <span class='grammar-green'>we</span> <span class='grammar-blue'>communicated</span> without much difficulty.<br>
:mexico: <span class='grammar-green'>Nosotros</span> <span class='grammar-pink'>estábamos</span> <span class='grammar-blue'>viajando</span> a Guanajuato cuando <span class='grammar-green'>yo</span> <span class='grammar-blue'>vi</span> a Sophie. <span class='grammar-green'>Ella</span> ya <span class='grammar-pink'>había</span> <span class='grammar-blue'>estudiado</span> español, así que <span class='grammar-green'>nosotros</span> <span class='grammar-blue'>nos comunicamos</span> sin mucha dificultad.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Auxiliary verb (verbo auxiliar).</span>**<br>
**\*<span class='grammar-blue'>Main verb (verbo principal).</span>**</sub>

## Conclusión

El **simple past** cuenta qué ocurrió, el **past progressive** muestra qué estaba ocurriendo y el **past perfect** explica qué había ocurrido antes. No necesitas incluir los tres tiempos en cada oración. Elige el tiempo que muestre con mayor claridad la función de cada acción dentro de tu historia.
