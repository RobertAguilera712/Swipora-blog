Summary: Aprende las formas, los usos y las estructuras principales del verbo to be en presente.

El **verb to be** es uno de los verbos más importantes del inglés. Sus significados principales son **ser** y **estar**, aunque su traducción depende del contexto. Lo usamos para hablar de identidad, edad, características, estados, ubicación, origen, hora y clima.

En presente tiene tres formas: **am**, **are** e **is**.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>am</span> a teacher.<br>
:mexico: <span class='grammar-pink'>Soy</span> maestro.<br><br>
:us: <span class='grammar-green'>You</span> <span class='grammar-pink'>are</span> <span class='grammar-blue'>tired</span>.<br>
:mexico: <span class='grammar-pink'>Estás</span> <span class='grammar-blue'>cansado</span>.<br><br>
:us: <span class='grammar-green'>He</span> <span class='grammar-pink'>is</span> <span class='grammar-blue'>strong</span>.<br>
:mexico: <span class='grammar-pink'>Es</span> <span class='grammar-blue'>fuerte</span>.<br><br>
:us: <span class='grammar-green'>She</span> <span class='grammar-pink'>is</span> at home.<br>
:mexico: <span class='grammar-pink'>Está</span> en casa.<br><br>
:us: <span class='grammar-green'>It</span> <span class='grammar-pink'>is</span> <span class='grammar-blue'>cloudy</span>.<br>
:mexico: <span class='grammar-pink'>Está</span> <span class='grammar-blue'>nublado</span>.<br><br>
:us: <span class='grammar-green'>We</span> <span class='grammar-pink'>are</span> students.<br>
:mexico: <span class='grammar-pink'>Somos</span> estudiantes.<br><br>
:us: <span class='grammar-green'>They</span> <span class='grammar-pink'>are</span> <span class='grammar-blue'>angry</span>.<br>
:mexico: <span class='grammar-pink'>Están</span> <span class='grammar-blue'>enojados</span>.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>
**\*<span class='grammar-blue'>Adjective (adjetivo).</span>**</sub>

En resumen, cada sujeto se combina con una forma específica:

<div class="grammar" markdown="1">
<span class='grammar-green'>I</span> → <span class='grammar-pink'>am</span><br>
<span class='grammar-green'>You, we, they</span> → <span class='grammar-pink'>are</span><br>
<span class='grammar-green'>He, she, it</span> → <span class='grammar-pink'>is</span>
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>

## Usos del Verb To Be

### Para hablar de la edad

En español expresamos la edad con **tener**; en inglés usamos **to be**. Por eso, *I have 20 years* no es correcto.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>am</span> 24 years old.<br>
:mexico: Tengo 24 años.<br><br>
:us: <span class='grammar-green'>She</span> <span class='grammar-pink'>is</span> 22 years old.<br>
:mexico: Tiene 22 años.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

### Para describir con adjetivos

Usamos **to be** antes de un adjetivo para describir al sujeto.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>The car</span> <span class='grammar-pink'>is</span> <span class='grammar-blue'>fast</span>.<br>
:mexico: <span class='grammar-green'>El carro</span> <span class='grammar-pink'>es</span> <span class='grammar-blue'>rápido</span>.<br><br>
:us: <span class='grammar-green'>The students</span> <span class='grammar-pink'>are</span> <span class='grammar-blue'>quiet</span>.<br>
:mexico: <span class='grammar-green'>Los estudiantes</span> <span class='grammar-pink'>están</span> <span class='grammar-blue'>callados</span>.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>
**\*<span class='grammar-blue'>Adjective (adjetivo).</span>**</sub>

### Para identificar al sujeto

Usamos **to be** para indicar la identidad, profesión o función de una persona.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>Laura</span> <span class='grammar-pink'>is</span> an architect.<br>
:mexico: <span class='grammar-green'>Laura</span> <span class='grammar-pink'>es</span> arquitecta.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

### Para definir al sujeto

Usamos **to be** para explicar qué es algo.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>A puppy</span> <span class='grammar-pink'>is</span> a baby dog.<br>
:mexico: <span class='grammar-green'>Un cachorro</span> <span class='grammar-pink'>es</span> un perro bebé.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

### Para expresar ubicación

Usamos **to be** para decir dónde se encuentra alguien o algo.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>The Eiffel Tower</span> <span class='grammar-pink'>is</span> in Paris.<br>
:mexico: <span class='grammar-green'>La Torre Eiffel</span> <span class='grammar-pink'>está</span> en París.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

### Para indicar el lugar de origen

La estructura **to be + from** indica de dónde es una persona.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>We</span> <span class='grammar-pink'>are</span> from Mexico.<br>
:mexico: <span class='grammar-pink'>Somos</span> de México.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>

### Para hablar de estados físicos y emocionales

Algunas expresiones que llevan **tener** en español se forman con **to be** en inglés.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>They</span> <span class='grammar-pink'>are</span> <span class='grammar-blue'>happy</span>.<br>
:mexico: <span class='grammar-pink'>Están</span> <span class='grammar-blue'>felices</span>.<br><br>
:us: <span class='grammar-green'>The baby</span> <span class='grammar-pink'>is</span> <span class='grammar-blue'>hungry</span>.<br>
:mexico: <span class='grammar-green'>El bebé</span> tiene hambre.<br><br>
:us: <span class='grammar-green'>The dog</span> <span class='grammar-pink'>is</span> <span class='grammar-blue'>thirsty</span>.<br>
:mexico: <span class='grammar-green'>El perro</span> tiene sed.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>
**\*<span class='grammar-blue'>Adjective (adjetivo).</span>**</sub>

En español decimos **tener hambre** y **tener sed**, pero en inglés estas sensaciones se consideran estados físicos y se expresan con **to be**: **to be hungry** y **to be thirsty**. No debemos traducir estas estructuras palabra por palabra.

### Para hablar del clima y la temperatura

En inglés usamos **it** como sujeto para hablar del clima. En español normalmente usamos una expresión impersonal y no traducimos **it**.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>It</span> <span class='grammar-pink'>is</span> <span class='grammar-blue'>cold</span> today.<br>
:mexico: Hoy hace frío.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>
**\*<span class='grammar-blue'>Adjective (adjetivo).</span>**</sub>

### Para decir la hora

El sujeto de las expresiones de tiempo en inglés es **it**. En español decimos la hora con una estructura diferente.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>It</span> <span class='grammar-pink'>is</span> three o'clock.<br>
:mexico: Son las tres.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

### Para decir la fecha o el día

También usamos **it** para indicar el día o la fecha.

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>It</span> <span class='grammar-pink'>is</span> Monday.<br>
:mexico: Hoy es lunes.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

### Con there is / there are

Usamos **there is** con sustantivos singulares y **there are** con sustantivos plurales para indicar que algo existe.

<div class="grammar" markdown="1">
:us: <span class='grammar-purple'>There</span> <span class='grammar-pink'>is</span> a book on the desk.<br>
:mexico: Hay un libro sobre el escritorio.<br><br>
:us: <span class='grammar-purple'>There</span> <span class='grammar-pink'>are</span> two students outside.<br>
:mexico: Hay dos estudiantes afuera.
</div>

<sub>**\*<span class='grammar-purple'>There.</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

### En expresiones impersonales con it

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>It</span> <span class='grammar-pink'>is</span> <span class='grammar-blue'>important</span> to <span class='grammar-blue'>eat</span> well.<br>
:mexico: <span class='grammar-green'>Comer bien</span> <span class='grammar-pink'>es</span> <span class='grammar-blue'>importante</span>.<br><br>
:us: <span class='grammar-green'>It</span> <span class='grammar-pink'>is</span> <span class='grammar-blue'>easy</span> to <span class='grammar-blue'>learn</span> with practice.<br>
:mexico: <span class='grammar-green'>Aprender con práctica</span> <span class='grammar-pink'>es</span> <span class='grammar-blue'>fácil</span>.
</div>

## Oraciones negativas con el Verb To Be

Colocamos **not** después de **am**, **are** o **is**. No necesitamos un verbo auxiliar.

<div class="grammar" markdown="1">
<span class='grammar-green'>Subject</span> + <span class='grammar-pink'>am / are / is</span> + <span class='grammar-red'>not</span> + complement
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>
**\*<span class='grammar-red'>Negation (negación).</span>**</sub>

<div class="grammar" markdown="1">
:us: <span class='grammar-green'>I</span> <span class='grammar-pink'>am</span> <span class='grammar-red'>not</span> <span class='grammar-blue'>tired</span>.<br>

## Contracciones con el Verb To Be

Las contracciones son frecuentes al hablar y en textos informales.

<div class="grammar" markdown="1">
<span class='grammar-green'>I</span><span class='grammar-pink'>'m</span> = <span class='grammar-green'>I</span> <span class='grammar-pink'>am</span><br>
<span class='grammar-green'>You</span><span class='grammar-pink'>'re</span> = <span class='grammar-green'>You</span> <span class='grammar-pink'>are</span><br>
<span class='grammar-green'>He</span><span class='grammar-pink'>'s</span> = <span class='grammar-green'>He</span> <span class='grammar-pink'>is</span><br>
<span class='grammar-green'>She</span><span class='grammar-pink'>'s</span> = <span class='grammar-green'>She</span> <span class='grammar-pink'>is</span><br>
<span class='grammar-green'>It</span><span class='grammar-pink'>'s</span> = <span class='grammar-green'>It</span> <span class='grammar-pink'>is</span><br>
<span class='grammar-green'>We</span><span class='grammar-pink'>'re</span> = <span class='grammar-green'>We</span> <span class='grammar-pink'>are</span><br>
<span class='grammar-green'>They</span><span class='grammar-pink'>'re</span> = <span class='grammar-green'>They</span> <span class='grammar-pink'>are</span>
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

En las contracciones negativas, la parte del verbo permanece en rosa y **n't**, incluido el apóstrofo, aparece en rojo.

<div class="grammar" markdown="1">
<span class='grammar-pink'>is</span><span class='grammar-red'>n't</span> = <span class='grammar-pink'>is</span> <span class='grammar-red'>not</span><br>
<span class='grammar-pink'>are</span><span class='grammar-red'>n't</span> = <span class='grammar-pink'>are</span> <span class='grammar-red'>not</span><br><br>
:us: <span class='grammar-green'>I</span><span class='grammar-pink'>'m</span> <span class='grammar-red'>not</span> <span class='grammar-blue'>busy</span>.<br>
:mexico: <span class='grammar-red'>No</span> <span class='grammar-pink'>estoy</span> <span class='grammar-blue'>ocupado</span>.<br><br>
:us: <span class='grammar-green'>She</span> <span class='grammar-pink'>is</span><span class='grammar-red'>n't</span> <span class='grammar-blue'>angry</span>.<br>
:mexico: <span class='grammar-red'>No</span> <span class='grammar-pink'>está</span> <span class='grammar-blue'>enojada</span>.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>
**\*<span class='grammar-blue'>Adjective (adjetivo).</span>**<br>
**\*<span class='grammar-red'>Negation (negación).</span>**</sub>

No existe la contracción *amn't*. Con **I am not**, usamos **I'm not**.

## Preguntas de Sí o No con el Verb To Be

Para formularlas, colocamos **to be** antes del sujeto.

<div class="grammar" markdown="1">
<span class='grammar-pink'>Am / Are / Is</span> + <span class='grammar-green'>subject</span> + complement + ?
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**</sub>

<div class="grammar" markdown="1">
:us: <span class='grammar-pink'>Are</span> <span class='grammar-green'>you</span> <span class='grammar-blue'>ready</span>?<br>
:mexico: ¿<span class='grammar-pink'>Estás</span> <span class='grammar-blue'>listo</span>?<br><br>
:us: <span class='grammar-pink'>Is</span> <span class='grammar-green'>Daniel</span> at work?<br>
:mexico: ¿<span class='grammar-pink'>Está</span> <span class='grammar-green'>Daniel</span> en el trabajo?<br><br>
:us: Yes, <span class='grammar-green'>he</span> <span class='grammar-pink'>is</span>. / No, <span class='grammar-green'>he</span> <span class='grammar-pink'>is</span><span class='grammar-red'>n't</span>.<br>
:mexico: Sí, <span class='grammar-pink'>está</span>. / <span class='grammar-red'>No</span>, <span class='grammar-red'>no</span> <span class='grammar-pink'>está</span>.
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>
**\*<span class='grammar-blue'>Adjective (adjetivo).</span>**<br>
**\*<span class='grammar-red'>Negation (negación).</span>**</sub>

En respuestas afirmativas cortas no contraemos el verbo: decimos **Yes, I am**, no *Yes, I'm*.

## WH Questions with the Verb To Be

Estas preguntas solicitan información específica. Colocamos la palabra interrogativa, después **to be** y finalmente el sujeto.

<div class="grammar" markdown="1">
<span class='grammar-purple'>WH word</span> + <span class='grammar-pink'>am / are / is</span> + <span class='grammar-green'>subject</span> + complement + ?
</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>
**\*<span class='grammar-purple'>WH question word (palabra interrogativa).</span>**</sub>

<div class="grammar" markdown="1">
:us: <span class='grammar-purple'>Where</span> <span class='grammar-pink'>are</span> <span class='grammar-green'>you</span> from?<br>
:mexico: ¿<span class='grammar-purple'>De dónde</span> <span class='grammar-pink'>eres</span>?<br><br>

:us: <span class='grammar-purple'>Why</span> <span class='grammar-pink'>is</span> <span class='grammar-green'>she</span> <span class='grammar-blue'>sad</span>?<br>
:mexico: ¿<span class='grammar-purple'>Por qué</span> <span class='grammar-pink'>está</span> <span class='grammar-blue'>triste</span>?<br><br>

</div>

<sub>**\*<span class='grammar-green'>Subject (sujeto).</span>**<br>
**\*<span class='grammar-pink'>Verb to be.</span>**<br>

Recuerda: en una afirmación el sujeto aparece antes del verbo; en una pregunta, el verbo aparece antes del sujeto.
